## Detailed Findings

### 1. Forbidden Em Dash Usage
- **Priority:** HIGH
- **Tier:** Hard Gate
- **Rule:** R-02 (Copywriting)
- **Locations:**
  - `frontend/src/app/layout.tsx:5`
  - `frontend/src/app/admin/charges/page.tsx:275, 288, 301, 316`
  - `frontend/src/components/admin/ChargesConfigTable.tsx:153`
  - `frontend/src/components/admin/TariffPreviewDrawer.tsx:250-271`
  - `frontend/src/components/admin/AddChargeDrawer.tsx:615`
- **Reason:** Em dash (`—`) characters appear in document title, loading/empty table placeholders, and option subtitles where colons, hyphens, or "N/A" must be used.

### 2. Missing Universal Interactive Cursor States
- **Priority:** HIGH
- **Tier:** Hard Gate
- **Rule:** R-39 (Accessible Semantics & Interaction Affordances)
- **Location:** `frontend/src/app/globals.css:5-44`
- **Reason:** Tailwind base preflight resets buttons to `cursor: default`; base CSS lacks universal `cursor: pointer` on enabled controls and `cursor: not-allowed` on disabled controls.

### 3. Missing Reduced Motion Media Query
- **Priority:** HIGH
- **Tier:** Hard Gate
- **Rule:** R-39 (Accessible Semantics & Interaction Affordances)
- **Location:** `frontend/src/app/globals.css`
- **Reason:** CSS lacks a `@media (prefers-reduced-motion: reduce)` declaration to immediately disable non-essential spinner rotations and slide-in transitions.

### 4. Missing Explicit Dimensions on Media
- **Priority:** HIGH
- **Tier:** Hard Gate
- **Rule:** R-40 (Performance Mechanisms)
- **Location:** `frontend/src/components/rates/AirlineLogo.tsx:86-93`
- **Reason:** Airline logo `<img>` tags lack explicit `width` and `height` HTML attributes, risking Cumulative Layout Shift (CLS).

### 5. Removed Focus Indicators on Custom Controls
- **Priority:** HIGH
- **Tier:** Hard Gate
- **Rule:** R-32 (Keyboard Accessibility)
- **Locations:**
  - `frontend/src/components/admin/ChargesConfigTable.tsx:229, 392`
  - `frontend/src/components/admin/AddChargeDrawer.tsx:962`
  - `frontend/src/components/rates/SearchableDestinationSelect.tsx:175`
- **Reason:** Toggle switch buttons and dropdown triggers use `outline-none` without providing an explicit `:focus-visible` ring.

### 6. Missing Empty Search State in Corridors Table
- **Priority:** HIGH
- **Tier:** Hard Gate
- **Rule:** R-27 (UI States)
- **Location:** `frontend/src/app/admin/corridors/page.tsx:171-214`
- **Reason:** When search filter text matches zero ports, the table renders an empty `<tbody>` with no feedback row.

### 7. Unnecessary Glassmorphism on Dense Table Header
- **Priority:** MEDIUM
- **Tier:** Purpose-Gate
- **Rule:** R-10 (Glassmorphism)
- **Location:** `frontend/src/components/admin/TariffPreviewDrawer.tsx:226`
- **Reason:** Sticky table header uses `backdrop-blur-xs` over a nearly opaque background (`bg-slate-100/95`) without serving visual hierarchy.

### 8. Generic Verb in Primary CTA
- **Priority:** LOW
- **Tier:** Quality Locks
- **Rule:** R-15 (Call to Action)
- **Location:** `frontend/src/components/rates/RateSearchForm.tsx:487`
- **Reason:** Button copy uses "Discover Pure Buy Rates" containing the prohibited generic verb "Discover".

### 9. Over-Decorated Button Typography
- **Priority:** LOW
- **Tier:** Quality Locks
- **Rule:** R-06 (Typography)
- **Location:** `frontend/src/components/rates/RateSearchForm.tsx:477`
- **Reason:** Primary rate calculation button applies `uppercase tracking-wider font-black` typical of generic marketing templates rather than clean utility software.
